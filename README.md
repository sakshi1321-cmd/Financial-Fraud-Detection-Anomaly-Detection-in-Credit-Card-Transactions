# Financial Fraud Detection: Anomaly Detection in Credit Card Transactions
Course-end project analysing 389K+ credit card transactions to identify fraud patterns and unusual spending behaviour, framed as a fraud detection scenario for a financial services company.

## Tools
SQL, Python (pandas, matplotlib), Tableau

## What I did
- **SQL:** Explored the data (transaction counts, top merchants, average amount by category), calculated the fraud rate, joined transaction and location tables, and aggregated spending by category, gender and day of week.
- **Python (EDA):** Checked data dimensions, missing values, distributions, outliers and correlations; compared `amt` across fraud and non-fraud transactions; wrote an EDA report for fraud detection.
- **Tableau:** Built an interactive dashboard with a box plot of spending by gender and category, geographic maps of transactions and fraud locations, a monthly time-series trend and an inflation-adjusted amount view.

## Dataset
`cc_data.csv` and `location_data` (credit card transactions with category, amount, gender, city population, location and fraud label).Credit card fraud detection analysis on 389K+ transactions using SQL, Python and Tableau. Covers data exploration, EDA, fraud pattern analysis by category, gender and location, and an interactive Tableau dashboard.
